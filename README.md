## ✨ Features

| Feature | Description |
|---|---|
| 🌡️ **Current Weather** | Temperature · Feels Like · Min/Max · Humidity · Pressure · Wind |
| 📅 **5-Day Forecast** | Daily cards with weather icon, temp, humidity and wind |
| ⚡ **In-Memory Cache** | Instant repeat lookups with automatic TTL eviction |
| 📊 **Live Dashboard Stats**| Total searches, most searched city, cache hits, API calls, and favorites count |
| 💡 **Weather Insights** | Rule-based natural weather summaries generated by Java backend |
| ⭐ **Favorite Cities** | Add, remove and manage favorites synced with Spring Boot REST API |
| 🕐 **Search History** | Backend-managed recent searches (max 10, deduplicated) with timestamps |
| 🔄 **Unit Conversions** | Backend utility for °C↔°F, km↔miles, and m/s↔km/h conversions |
| 🌗 **Dark / Light Theme** | One-click theme toggle preference |
| 📱 **Fully Responsive** | Works on mobile, tablet and desktop |

## 🚀 Getting Started

> **Prerequisites:** Java 17+ / 21+ &nbsp;|&nbsp; Node.js 18+

### ① Start the Backend

```bash
cd backend
./mvnw spring-boot:run
```

API available at → `http://localhost:8080`

### ② Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

App available at → `http://localhost:5173`

## 🔌 REST API Endpoints

| Method | Endpoint | Description |
|:---:|---|---|
| `GET` | `/api/weather?city=London` | Full weather summary & insights (cached) |
| `GET` | `/api/weather/current?city=London` | Current weather details |
| `GET` | `/api/weather/forecast?city=London` | 5-day / 3-hour forecast |
| `GET` | `/api/weather/history` | Retrieve recent search history |
| `DELETE`| `/api/weather/history` | Clear search history |
| `DELETE`| `/api/weather/history/{city}` | Remove city from search history |
| `GET` | `/api/favorites` | Retrieve favorite cities |
| `POST` | `/api/favorites` | Add city to favorites |
| `DELETE`| `/api/favorites/{city}` | Remove city from favorites |
| `GET` | `/api/weather/statistics` | Retrieve dashboard search metrics |
| `DELETE`| `/api/weather/cache` | Clear in-memory weather cache |
| `POST` | `/api/weather/convert` | Execute temperature/unit conversions |
| `GET` | `/api/health` | Backend service health check |

<details>
<summary>📄 Error Response Format</summary>

```json
  "status": 400,
  "error": "Invalid City Input",
  "message": "City name cannot contain invalid characters.",
  "path": "/api/weather"
}
```

## ⚙️ Configuration

`weather-backend/src/main/resources/application.properties`

```properties
api.key=your_openweathermap_api_key
api.base-url=https://api.openweathermap.org/data/2.5
server.port=8080
```

> Get a free API key → [openweathermap.org/api](https://openweathermap.org/api)
